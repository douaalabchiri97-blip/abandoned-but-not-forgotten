# Abandoned but Not Forgotten

> Every object left in space has a story. This project gives it a voice.

An interactive web experience built for **NASA Space Apps Challenge 2026** that explores abandoned space objects and forgotten missions — the satellites, probes, and tools humans left behind, and what they can still teach us.

## The Problem
Thousands of objects have been left in space after their missions ended. They are often forgotten, but they carry scientific, historical, and human value. Most people never hear their stories.

## Our Solution
Abandoned but Not Forgotten turns space debris and forgotten missions into an emotional, interactive journey. Instead of charts and numbers only, the user discovers each object through storytelling, visuals, and exploration.

## Key Features
- Interactive storytelling for abandoned space objects
- Explore forgotten missions and their history
- Beautiful, immersive space-themed design
- Simple and accessible experience for all ages
- Works directly in the browser, no installation needed

## How to Use It
- Open the HTML file in any modern browser
- Explore the story from the beginning
- Click through the objects to discover their missions

## Technologies Used
- HTML
- CSS
- JavaScript

## Why It Matters
Space exploration is not only about the future. It is also about remembering what we left behind, learning from it, and thinking
